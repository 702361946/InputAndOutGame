# 虚拟光标实现分析

## 改造目标

当前虚拟光标基于以下参考项目的设计思想改造：

```text
D:\xm\cs\Controller_and_Keyboard_Mouse
```

参考项目将输入分为两种模式：

- 键鼠模式：使用鼠标提供的绝对屏幕坐标。
- 手柄模式：将摇杆方向乘以灵敏度后，累加到当前虚拟光标坐标。

同时由独立的位置对象保存光标坐标、屏幕大小并负责边界约束。

Godot 实现保留了上述模型，并针对当前项目补充：

- 按帧时间计算的移动速度。
- 按下、移动、释放三个完整指针阶段。
- 鼠标与手柄共用的工厂拖拽入口。
- 视口坐标到世界坐标的统一转换。
- 游戏客户区内隐藏系统鼠标并持续渲染虚拟光标。

## 参考设计映射

| C# 参考实现 | Godot 实现 |
| --- | --- |
| `Position._mousePosition` | `VirtualCursor.viewport_position` |
| `Position._screenSize` | `Viewport.get_visible_rect().size` |
| `Position.ResetMousePosition()` | `_set_viewport_position()` 和 `_clamp_to_viewport()` |
| `Operation._mode` | `VirtualCursor.InputMode` |
| `key` 模式传入绝对鼠标坐标 | `_use_mouse_position(event.position)` |

参考实现中的摄像机位置管理没有直接迁移。当前项目已经通过 `MainMap._viewport_to_world()` 处理相机画布变换，重复维护摄像机坐标会形成第二套状态源。

## VirtualCursor

### 输入模式

`VirtualCursor` 定义两种模式：

```text
KEYBOARD_MOUSE
CONTROLLER
```

切换规则如下：

- 收到鼠标移动或鼠标按钮事件时切换到 `KEYBOARD_MOUSE`。
- 收到非零 `VCTo_*` 输入或手柄 `VCClick` 时切换到 `CONTROLLER`。
- 摇杆回中后保持当前位置和当前模式，不再跳回鼠标位置。
- 从手柄模式切回鼠标时，不要求先产生鼠标移动；鼠标按钮事件自身携带的位置也会完成模式和坐标同步。

输入模式只表示当前由键鼠还是手柄控制指针，不参与光标显隐。鼠标位于游戏客户区内时隐藏系统鼠标并显示虚拟光标贴图；鼠标离开客户区进入系统标题栏或窗口边框时临时恢复系统鼠标，重新进入游戏区域后再次隐藏。节点退出场景时也会恢复系统鼠标。

### 位置管理

光标只保存一个 `Vector2` 类型的 `viewport_position`，坐标契约固定为逻辑视口坐标。

每次更新都会限制在：

```text
(0, 0) 到 (viewport_width - 1, viewport_height - 1)
```

视口大小变化时会重新约束当前坐标。

### 手柄移动

四个输入动作通过 `Input.get_vector()` 合成为方向向量：

```gdscript
viewport_position += input_vector * controller_speed * delta
```

默认速度为 `640 px/s`。该计算支持左、右、上、下和对角线，并且不依赖运行帧率。

### 指针信号

虚拟光标对外提供：

```text
pointer_moved(viewport_position)
pointer_pressed(viewport_position)
pointer_released(viewport_position)
input_mode_changed(mode)
```

鼠标和手柄都由 `VirtualCursor` 发出相同的 `pointer_*` 信号：

- 鼠标移动先同步模式和视口坐标，再发出 `pointer_moved`。
- 鼠标按钮先同步按钮事件携带的坐标，然后继续判断 `VCClick`，不会在动作判断前提前返回。
- 手柄 `VCClick` 先切换到手柄模式，再发出按下或释放信号。
- 未绑定到 `VCClick` 的鼠标按钮只同步输入模式和坐标，不会误发点击信号。

## 显示层

`VirtualCursor.tscn` 的根节点由 `Node2D` 改为 `CanvasLayer`：

- `layer = 100`，使光标稳定显示在地图内容上方。
- 光标位置不受 `Camera2D` 平移或缩放影响。
- `Sprite2D.centered = true`，使准星中心圆点与逻辑指针坐标重合。
- `Sprite2D.visible = true`，键鼠和手柄模式下均渲染虚拟光标。
- `VirtualCursor._ready()` 将系统鼠标设置为 `MOUSE_MODE_HIDDEN`。
- `NOTIFICATION_WM_MOUSE_EXIT` 临时显示系统鼠标，使系统窗口标题栏和边框可操作。
- `NOTIFICATION_WM_MOUSE_ENTER` 在鼠标返回游戏客户区时再次隐藏系统鼠标。

所有世界交互都由消费者将视口坐标转换为世界坐标，显示坐标和交互坐标不再混用。

## MainMap 接入

`MainMap` 在 `_ready()` 中连接虚拟光标的移动、按下和释放信号，不再自行解析鼠标按钮或鼠标移动事件。这样可以避免 `MainMap._input()` 与 `VirtualCursor._input()` 竞争同一个鼠标事件。

鼠标路径：

```text
InputEventMouseButton / InputEventMouseMotion
  -> VirtualCursor._input()
  -> pointer_pressed / pointer_released / pointer_moved
  -> MainMap._handle_pointer_*()
  -> _viewport_to_world()
  -> 工厂命中和拖拽
```

手柄路径：

```text
InputEventJoypadButton / Input.get_vector()
  -> VirtualCursor
  -> pointer_pressed / pointer_released / pointer_moved
  -> MainMap._handle_pointer_*()
  -> _viewport_to_world()
  -> 工厂命中和拖拽
```

两种输入最终共用：

- 工厂命中检测。
- 拖拽偏移计算。
- 16×16 网格吸附。
- 可见世界区域约束。
- 拖拽开始、移动、结束和 Escape 取消。

`MainMap` 只在 `_unhandled_key_input()` 中处理 Escape，避免根节点 `_input()` 抢先消费鼠标事件。重复按下事件也不会覆盖首次拖拽记录的偏移和取消位置。

## 当前输入绑定

| 动作 | 绑定 |
| --- | --- |
| `VCClick` | 鼠标左键、手柄按钮 0 |
| `VCTo_up` / `VCTo_down` | 手柄轴 1 |
| `VCTo_left` / `VCTo_right` | 手柄轴 0 |

参考项目中的 `W/A/S/D` 转向方法没有加入当前 InputMap。当前键鼠模式继续使用真实鼠标，避免占用未来可能用于相机或角色操作的键盘按键。

## 验证结果

使用 Godot 4.7 无头模式实例化真实 `MainMap.tscn`，构造输入事件直接验证 `VirtualCursor._input()`，并通过真实信号连接验证 `MainMap` 拖拽。测试命令：

```powershell
Godot_v4.7-stable_win64_console.exe --headless --path . --script res://tests/VirtualCursorInputSmokeTest.gd
```

系统鼠标模式由真实窗口 DisplayServer 验证：

```powershell
Godot_v4.7-stable_win64_console.exe --path . --rendering-method gl_compatibility --audio-driver Dummy --script res://tests/VirtualCursorDisplaySmokeTest.gd
```

2026 年 7 月 29 日验证通过：

- 左、右、上、下四个方向均能移动。
- 默认速度下按 `0.1` 秒计算移动 `64` 像素，符合 `640 px/s`。
- 鼠标移动能够发出一次 `pointer_moved`。
- 鼠标左键按下和释放各发出一次对应信号。
- 鼠标右键不会误发 `VCClick` 指针信号。
- 手柄点击与鼠标点击共用相同的按下和释放信号。
- 从手柄模式直接点击鼠标，无需先移动即可恢复键鼠模式并同步点击坐标。
- 场景以键鼠模式启动时虚拟光标可见，系统鼠标隐藏。
- 切换到手柄或切回鼠标时显隐状态保持不变。
- 鼠标离开游戏客户区时系统鼠标恢复，可操作窗口标题栏和边框。
- 鼠标重新进入客户区时系统鼠标再次隐藏。
- 退出虚拟光标场景后系统鼠标恢复显示。
- 鼠标在 `TitleBlock` 中心按下时能够通过完整 Viewport 输入传播完成拖拽。
- 手柄虚拟光标以中心热点位于 `TitleBlock` 时能够完成按下、移动和释放。
- 鼠标统一指针信号能够完成 `FactoryBase` 的选择、拖动和释放。

## 保留事项

- `process_mode = 3` 保留了原实现的始终处理行为，暂停场景时虚拟光标仍可移动。
- 当前模式切换以实际鼠标事件和手柄动作触发；若手柄存在明显摇杆漂移，应提高 InputMap deadzone。
- `VirtualCursor` 在 `_input()` 阶段统一指针事件；命中工厂后 `MainMap` 会将当前事件标记为已处理。未来增加覆盖式 UI 时，仍应单独定义 UI 与世界拖拽的输入优先级。
